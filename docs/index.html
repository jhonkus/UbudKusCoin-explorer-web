Overview

Everything you need to inspect the chain

Key modules exposed by the explorer, backed by a secure server-side gRPC gateway.

Blocks

Browse validated blocks, inspect individual blocks by height or hash, and follow the chain as it grows.

Transactions

Review confirmed transactions, drill into details by hash, and trace activity across the network.

Accounts

Explore top accounts by balance, view balances, validation counts, and linked activity in one place.

Pending Pool

Watch the mempool with near-real-time updates of queued transactions awaiting confirmation.

Live Charts

Visualize transaction amount and count trends with refreshable charts driven by the node read model.

Powerful Search

Search any address, block, or transaction hash using the node's block, transaction, and account read models.

Architecture

Secure by design

The browser never talks directly to a validator.

🌐 Browser Explorer UI (Next.js)
→
🖥 Next.js Server API routes & gRPC gateway
→
🔒 Node UbudKusCoin gRPC services
  • Server-side API proxies read-only node queries to the node's gRPC services.
  • Connects to the native gRPC port, not the CometBFT RPC port.
  • Node endpoint is never exposed directly to browsers.
  • Returns 502 when the configured node is unavailable.

Get Started

Run it locally in minutes

Point the explorer at a UbudKusCoin node and start browsing.

  1. 1
    Clone the repository 
    git clone https://github.com/jhonkus/UbudKusCoin-explorer-web.git
  2. 2
    Install dependencies 
    npm install
  3. 3
    Configure the node endpoint 
    # .env.local
UKC_NODE_GRPC_URL=127.0.0.1:5000
  4. 4
    Start the dev server 
    npm run dev
