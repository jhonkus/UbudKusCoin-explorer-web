Node UbudKusCoin gRPC services
  • Server-side API proxies read-only queries to the node.
  • Connects via native gRPC, not CometBFT RPC.
  • Node endpoint is never exposed to browsers.
  • Returns 502 when the node is unreachable.

Get Started

Run it locally

Point the explorer at your UbudKusCoin node and start browsing.

  1. 1
    Clone the repository 
    git clone https://github.com/jhonkus/UbudKusCoin-explorer-web.git
  2. 2
    Install dependencies 
    npm install
  3. 3
    Configure node endpoint 
    # .env.local
UKC_NODE_GRPC_URL=127.0.0.1:5000
  4. 4
    Start the dev server 
    npm run dev
